# 喝了么（Heleme）：开发数据库
PostgreSQL 17，六张业务表，仅供本地开发。

启动：`docker compose up -d --wait`

连接：`docker compose exec db psql -U heleme -d heleme`

停止并保留数据：`docker compose stop`

密码保存在被 Git 忽略的 `.env` 中。上线前为应用创建受限数据库账号；当前初始化账号仅供开发。
初始迁移仅在数据卷首次初始化时执行；后续变更新增迁移文件。

甜度统一等级：0 无糖、1 微糖、2 三分糖、3 半糖、4 七分糖、5 全糖；未知留空并保留原始标签。这是推荐分类，不代表实际含糖量。
冰量：regular 正常冰、less 少冰、none 去冰、room 常温、warm 温、hot 热。
金额单位人民币元；评分 1–5；未知价格与未评分使用 NULL。
微信身份 provider_app_id 保存 AppID，provider_subject 保存 OpenID，由后端管理。
饮料删除后通过快照保留历史；业务优先使用 inactive 下架。

## 网页 Demo

要求 Node.js 22 或更新版本、Docker Compose v2。

```sh
docker compose up -d --wait
npm ci
npm run catalog:import
npm start
```

浏览器打开 http://127.0.0.1:3000 。菜单支持游客浏览；菜单由大陆中文采集数据导入，已停止自动生成虚构品牌，不会添加虚假的饮用历史。
支持饮料推荐、预算与品类筛选、尝鲜、收藏、记录与修改评分、历史搜索、偏好和 JSON 导出。

运行验证：保持 `npm start` 运行，在另一个终端运行 `npm test`。接口测试会创建一条临时记录，并在完成后删除；推荐单元测试不访问数据库。

网页采用原生 HTML/CSS/JavaScript，后端为 Node.js HTTP + pg，优先让 Demo 可运行；尚未迁移到 Vue/uni-app 或 NestJS。前后端使用同一服务，无额外前端构建步骤。
已支持用户名密码登录和按账号隔离的个人数据；当前服务仍绑定本机回环地址，生产部署还需要HTTPS、受限数据库账号及运维配置。
接口说明见 API.md，部署规则见 DEPLOYMENT.md。

macOS/Linux 可运行 `bash start-demo.sh` 完成密码生成、数据库启动、依赖安装和网页启动。Windows 可在 WSL 中运行该脚本，或按上面的命令手动操作。

## 中国大陆15品牌菜单

品牌总数为15家，采用[艾媒金榜2026年中国新式茶饮连锁品牌15强](https://ranking.iimedia.cn/ranking/161/624)，榜单统计截至2026-06-23，属于综合指标榜单，不是单一门店数排名。品牌清单和排名依据存于 `data/brands.json`。

品牌：蜜雪冰城、古茗、霸王茶姬、茶百道、沪上阿姨、书亦烧仙草、喜茶、益禾堂、茶颜悦色、1点点、奈雪的茶、CoCo都可、茉莉奶白、快乐番薯、爷爷不泡茶。

当前首批853款，来自“咖啡奶茶喝什么”第三方整理的大陆简体中文在售菜单，每品牌采集前3页；不保证完整菜单或成都门店实时供应。过滤纯英文产品、海外限定款、套餐、周边和明显非饮料商品，并按品牌与名称去重。不导入海外官网数据，也不再生成虚构品牌。

```sh
npm run catalog:crawl
npm run catalog:import
# 离线重解析已有快照
python3 scripts/crawl-catalog.py --offline
# 扩大采集页数，每品牌最多50页
npm run catalog:crawl -- --max-pages 10
npm run test:crawler
npm test
```

每次请求间隔1秒、超时30秒；不访问登录或点单私有接口。任一来源失败时不覆盖汇总文件。`data/catalog.json` 保存名称、整理品类、来源、地区、采集时间及参考价；原始快照位于被Git忽略的 `data/sources/`。数据库增量迁移002、003、004按版本执行，不重建数据卷。

普通导入按来源键更新，不自动移除缺失条目或改动上下架状态。经确认切换品牌范围时使用 `npm run catalog:import -- --replace-scope`，将范围外及未纳入本次数据集的旧条目设为inactive，保留ID、收藏与历史。本次替换前备份在 `backups/before-mainland-top15.dump`。

### 价格口径：成都

当前未取得可核验的成都美团门店价目表。美团公开入口检查记录在 `data/price-sources.json`，未把全国活动券价或全国参考价冒充成都门店价。

`reference_price` 为第三方页面参考价，页面显示“参考 ¥…”，并提示“成都门店价待核验”；`price`、`price_city`、`price_store` 均留空。参考价不参与“已核验价格”的预算筛选；推荐和随机选品中，勾选“包含价格待确认”时才包含此类产品；完整菜单浏览始终展示未知价格饮料。完整配料和甜度选项以实际点单页为准，未推断热量、配料或实际含糖量。

## 记录饮品

“记一杯”先选择品牌，再选择该品牌下的具体饮品。切换品牌会清空之前的饮品选择；从饮料卡片或“再来一杯”进入时自动选中对应品牌与饮品。编辑记录时锁定品牌及饮品，只修改甜度、冰量、金额、评分和备注。误记的记录可在“喝过的”点击“删除”，确认后永久移除，仅能删除自己的记录；统计和推荐随之更新。菜单在前端按品牌分组，记录和收藏继续引用原有饮品 ID，同名饮品不会混淆。

## 随机推荐与完整菜单浏览

点击“随机推荐”，推荐区直接随机展示最多3款饮料，点击“再随机推荐”换一组。候选遵守品牌、品类、预算和未知价格开关；候选足够时避开上一组，同组不重复。尝鲜模式优先推荐未喝过的饮料。推荐卡片可收藏或“记一杯”，随机推荐本身不保存饮用记录。

“发现更多饮料”使用自己的菜单品牌、品类和关键词，不受推荐预算、未知价格开关或推荐请求失败影响。默认显示已收录853款的总数，每次展示24款，可“显示更多”或“重置菜单筛选”。因此关闭未知价格推荐不会把完整菜单误显示为0款。

## 用户登录与管理

网页右上角“登录 / 注册”可创建普通账号。用户名为3–32位英文字母、数字或下划线，忽略大小写；密码为10–128个字符。游客可浏览完整菜单及随机推荐；登录后可保存个人记录、收藏、偏好并导出自己的数据。在“我的口味”可修改昵称和密码、退出登录。

### 创建管理员及接管原本机数据

在本机交互终端执行：

```sh
cd /Users/wfighter/Projects/Heleme
npm run user:admin
```

按提示设置管理员用户名、昵称和密码，密码不回显，也不接受命令行或环境变量密码。没有默认密码，公开注册永远只创建普通账号。命令会优先绑定尚未设置登录账号的原单人用户，从而保留其原有记录、收藏与偏好；已注册的其他账号不受影响。管理员登录后侧边栏出现“用户管理”，可按用户名/昵称搜索、分页查看、禁用及重新启用账号。不能修改自己的管理状态。禁用保留个人数据并立即撤销登录会话。

密码使用随机盐scrypt哈希，数据库只保存会话令牌哈希；会话存储在PostgreSQL，服务重启后可继续登录，绝对期限7天、闲置期限1天。Cookie为HttpOnly及SameSite=Strict。写入接口同时检查来源、JSON、自定义请求头和会话CSRF令牌；登录有数据库持久化限流。修改密码后所有会话均失效，需重新登录。

当前仍为本机HTTP开发服务；HTTPS部署时设置 `COOKIE_SECURE=1`，并按实际部署配置受信域名、反向代理及数据库最小权限。没有邮箱/短信找回密码或微信登录。管理员账号由你在终端选择密码创建，不会将密码输出或写入源码。迁移前备份为 `backups/before-accounts.dump`。
